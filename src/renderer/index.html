Paramètres

Sites de ce poste
Un site = un dossier de données. Le superviseur peut ainsi passer d'un site à l'autre depuis le même poste.
Responsables
Liste commune à tous les postes qui utilisent le même dossier.
Superviseurs (accès à tout, avec code PIN)
Enregistrés pour ce site. Pour changer un code, ajoutez à nouveau le même nom.
Agents mémorisés
Proposés quand on saisit un absent. Un nouveau nom s'ajoute automatiquement ; retirez ici les fautes de frappe.
Version
Pour mettre à jour tous les postes, déposez le nouvel installateur (Liaison-Installation-x.y.z.exe) dans ce dossier.

Diagnostic

Intro au choix du nom
Rugissement synthétisé
Animation de 3 secondes avec rugissement, jouée juste après le clic sur ce nom (un clic ou Échap pour passer). Sa photo apparaît au centre de l'anneau doré : cliquez sur sa bouche dans l'aperçu pour que la mâchoire s'ouvre au bon endroit. Son : un vrai rugissement (MP3, WAV…) remplace le rugissement synthétisé ; il démarre quand la mâchoire s'ouvre.
Écran bleu au choix du site
Faux écran bleu Windows en plein écran pendant 10 secondes quand cette personne choisit son site, puis l'appli reprend normalement (Échap pour l'arrêter).
